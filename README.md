# NGIS Offline Maps: map data

The offline map packages the NGIS Offline Maps app downloads, one per region of Ghana, served by
GitHub Pages from `stable/`. This repository holds data only, no app code.

## Sources and licences

- Map data © OpenStreetMap contributors, available under the Open Database Licence (ODbL):
  https://www.openstreetmap.org/copyright
- Map tiles schema © OpenMapTiles.
- Buildings: Google Open Buildings, CC BY 4.0 (https://sites.research.google/open-buildings/).
- Coastline and water: OpenStreetMap water polygons; Natural Earth (public domain).

The packages are a derived database of OpenStreetMap and are shared under the ODbL.
